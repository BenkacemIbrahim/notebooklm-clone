# Contributing to QUORRA

Thanks for contributing.

## Development Workflow

1. Fork or branch from `main`.
2. Install dependencies with `npm install`.
3. Run local development with `npm run dev`.
4. Validate before opening a PR:
   - `npm run lint`
   - `npm run typecheck`
   - `npm run build`

## Commit Guidelines

- Keep commits focused on a single concern.
- Use clear commit messages in imperative form.
- Avoid unrelated formatting-only changes unless requested.

## Pull Request Checklist

- [ ] Code builds locally
- [ ] Lint and type checks pass
- [ ] Documentation updated for behavior changes
- [ ] Screenshots included for visible UI changes

## Branch Naming

Use short, descriptive names:

- `feat/landing-copy-refresh`
- `fix/header-mobile-overflow`
- `docs/readme-architecture-update`
